# How to Use This Repo

**US LLC Guide for Non-Residents** — the no-fluff path from zero to a
live, compliant US LLC for founders living outside the US.

Pick the route that fits how you work:

## 1. As a Claude skill

1. Copy this repo's `SKILL.md` into your Claude skills folder (or
   upload it wherever your setup accepts skills).
2. Start a conversation and ask in this repo's domain, e.g.
   "I'm a founder in Pakistan — which state should I form my LLC in
   and what will it cost in total?"
3. Claude uses the checklist, state fees, EIN walkthrough, and
   deadlines from this repo to answer.

## 2. Inside Claude.ai

1. Create a Project in Claude.ai.
2. Paste the contents of `SKILL.md` into the Project's instructions,
   and/or add `SKILL.md`, `checklist.md`, `state-fees.md`,
   `ein-walkthrough.md`, and `tax-deadlines.md` as Project knowledge.
3. Ask your formation questions inside that Project.

## 3. With the Epics Deals MCP server (live answers)

These are static knowledge files. For live tool answers instead,
connect the Epics Deals MCP server:

- Endpoint: `https://epics-deals-mcp.epicsdeals.workers.dev/mcp`
- Add it as a remote MCP server in your AI client, then ask your
  LLC questions — the tools answer live instead of from static files.

## 4. As plain reference

1. Read the guides directly on GitHub: start with `README.md`, then
   `checklist.md` for the 10 steps in order.
2. Use `state-fees.md` when comparing states, `ein-walkthrough.md`
   when applying for the EIN, and `tax-deadlines.md` for compliance.
3. Download the markdown files for your own notes, docs, or filing
   preparation.

## 5. In other AI tools

1. Upload `SKILL.md` plus the guide files (`checklist.md`,
   `state-fees.md`, `ein-walkthrough.md`, `tax-deadlines.md`) as
   knowledge to a custom GPT, a Gemini Gem, or a notebook.
2. Ask in the same domain — state choice, total cost, EIN steps,
   deadlines.

## 6. Fork it

This repo is MIT licensed. Fork it, adapt the checklist and fees to
your own workflow or audience, and keep the verified figures current
(state fees change — confirm at the state's filing office).
